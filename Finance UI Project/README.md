2.Overview of Approach

Initially, I attempted to develop the project using React, as I am currently self-learning the framework. 
However, I realized that I was not able to implement my learning effectively within the given timeframe. 
To ensure timely completion of the assignment, I decided to switch to HTML, CSS, and JavaScript, along with Bootstrap.

My primary approach was to design a dashboard that presents financial data in a simple and intuitive manner, 
enabling users to understand their information easily without unnecessary complexity.

3.Explanation of Features.

+ A navigation bar is included to enable easy and intuitive navigation across the dashboard.
+ Summary cards display key financial metrics such as Total Balance, Total Income, Total Expense, and Total Savings, allowing users to quickly understand their financial status.
+ A time-based balance trend chart is implemented to visualize changes in balance over time.
+ A dynamic categorical expense breakdown chart is provided, where users can select the month and year to analyze spending patterns.
+ An Income vs Expense chart enables users to compare monthly financial inflows and outflows.
+ The Transactions section includes a detailed table with the following fields:
+ Date.
+ Amount.
+ Category.
+ Type (Income / Expense / Saving).
+ The table also supports searching, sorting, and filtering for better data accessibility and usability.
+ The transaction add form contains predefined categories like "Food", "Salary" etc. for easier access.

4.Basic Role Based UI
A toggle button is implemented to switch between Admin and Viewer roles.
+ Viewer Role:
  Can only view the financial data.
+ Admin Role:
  Can add transactions.
  Users can easily switch roles using the toggle button.



5.Insights Section

The dashboard provides key insights to help users better understand their finances:

+ Monthly balance comparison.
+ Highest spending category.
+ Total loan amount.
+ Recurring transactions.
+ Financial goals.


5.State Management

+ Basic state management is implemented using JavaScript to handle and update application data dynamically.

6.Optional Enhancements

The following additional features have been implemented:

+ Dark mode for improved user experience.
+ Data persistence using local storage.
+ Export functionality for data in CSV/JSON formats.
+ Export functionality for charts.
